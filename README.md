## Project Topic: E-Commerce Sales Analysis

### Project Overview

This Data Analysis project aims to generate insights into the sales performance of the e-commerce project over the past year. By analysing the various parameters in the data received, we seek to gather enough insight to make reasonable decisions, which then enable us to tell compelling stories around our data from the insights gained and to identify the best performance from our data.   

### Data Sources

The primary data source used here is Data Sale.csv, an open-source dataset that can be freely downloaded from online repositories such as Kaggle, FRED, or other data repositories.

### Tools Used

- MS Excel (for Data Cleaning) [Download](https://www.microsoft.com)
- SQL Server (for Querying and Analysis)
- Power BI ( for creating a report)
- MS PowerPoint (for presentation)
